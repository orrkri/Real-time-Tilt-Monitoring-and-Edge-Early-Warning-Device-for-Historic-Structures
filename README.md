## 基坑长期监测方案

整理日期：2026-10-10。已知条件为50 m×50 m正方形基坑、外围安装相机、允许安装墙面靶标，重点监测坑壁位移与法向隆起；视觉系统以独立完成该项全站仪监测作业为目标，精度目标为5 mm以内。
