# 基坑相机长期部署与耐候运维细则

日期：2026-10-06。适用于50 m×50 m基坑、四面墙固定靶标、外围高位相机、连续三维位移与坑壁法向隆起监测，目标为替代该作业的全站仪。相机数量、基坑深度、安装高度、退距和支护结构尚未确定。本文给出工程设计要求与试点建议，不作为基础、立杆及电气施工图；文中的数值算例不代表现场已经满足5 mm。

## 1. 长期稳定的基本架构

采用“基础与刚性机架降低位移—独立控制网估计相机位姿—图像及几何质量判定—同步三维测量—故障处理与维护”的完整链路。长期目标不是假设相机永远不动，而是相机的小幅位移可被识别、量化，并在验证范围内更新外参，避免误计为墙面变形。

两个相机同时移动也不能自动消除误差。两机相对位置稳定只能保持内部几何，不能建立相对于外部稳定坐标系的位移基准。墙面测点不得用于每轮强制拟合相机位姿，否则真实墙面整体移动可能被消除。

相机转动0.01°，在30 m视距下对应约5.24 mm的横向视线偏移；这只是角度误差敏感性示例，不是一般三维位移误差公式。钢构件长3 m、均匀温差40℃、膨胀系数约12×10⁻⁶/℃时，轴向伸缩约1.44 mm。日照导致的不均匀温差还可能弯曲机架。总误差必须包含温度、控制网、光学与空气扰动。

## 2. 安装基础与承力结构

### 2.1 选址

1. 结合支护、土层、降水范围、施工荷载和既有结构，划定可能移动的区域。坑外地面不自动等于稳定地面；不能用统一退距替代岩土判断。
2. 优先选择经核验稳定的结构或经设计的独立基础。附近建筑也须核查是否处于开挖、降水及荷载影响范围。
3. 避开围护墙、冠梁、支撑梁、临时栏杆、脚手架、板房、施工平台和未核查的回填土。即使局部看起来牢固，也可能与被测墙一起移动。
4. 核查升高镜头后的坑沿通视、角部遮挡、支撑遮挡和有效交会角，再确定安装高度。不能先造高杆，再期待光学几何自然满足要求。
5. 如果可用安装点都在影响区，需设计基础及独立视觉位姿测量，验证移动后的补偿能力；无法建立稳定基准时，不能仅凭加强支架保证5 mm。

### 2.2 建议结构

承力链路为：经设计的基础/稳定结构 → 短而刚的立柱或门架 → 有加劲肋的安装板 → 可锁紧的调姿座 → 相机。高度较大时优先评估有支撑的门架或空间框架，避免细长单杆；立柱截面、基础形式、埋深及锚栓由实际风荷载、土层、设备重量和振动要求确定。

相机尽量靠近承力节点，缩短悬臂。调姿机构仅安装时使用，完成对准后锁紧，不使用会巡航的云台。紧固件按厂家及结构设计扭矩安装，采用适合振动环境的防松构造，并设置可见的移位标记；不能依靠反复拧紧弥补结构刚度不足。

防护箱、遮阳罩、灯具和线缆支撑应避免把风荷载和拉力直接传给相机调姿座。外罩独立支撑时，需保证窗口与镜头在温度、风载和安装误差下仍不接触、不遮挡。补光灯、电源和风扇尽量远离光学承力路径。

未经动态分析，不在相机与基座之间随意加厚橡胶垫、软减振吊架；软连接可能增加低频摆动、蠕变和零点漂移。施工振动优先从选址、刚度、短曝光和质量拒绝处理，专用减振装置需完成测量验证。

线缆在结构上先固定，再以无张力维护余量连接相机；穿箱处设置防水接头和滴水弯。缆线不得悬挂在镜头或调姿座上。安装防撞护栏、编号和维护通道，防撞设施与精密承力机架避免相互传力。

基础按设计完成养护与加载检查，机架完成安装稳定性观察后再建立初始测量基线。不以拍到一张清晰图像代替基础稳定性验收。

## 3. 相机运动的识别与补偿

### 3.1 测量点与控制点分离

墙面编码靶标是被测点；外部控制靶标用于定义稳定坐标系；独立检查靶标用于验证相机位姿校正是否准确。三种用途在台账及软件中分开，不能混用。

若控制点可直接进入测量相机视场，每台初步按6–10个控制目标及至少2个不参与位姿拟合的检查目标评估，最终数量由可见性与误差预算决定。目标应分布在视场不同位置，尽量具有空间深度跨度，避免集中在一个小角落、近共线或严重掠视。已知共面目标并非绝对不可用，但位姿可观测性和最差方向误差需单独验证。

控制目标应有经过检验的三维坐标及尺度依据。相机看到一个“固定物体”并不意味着已经具有可靠的三维控制。可通过可溯源标定尺、受约束的多视角联合测量建立视觉控制网，但器具温度变化、控制网精度和初始坐标不确定度必须计入预算。

### 3.2 控制目标不在主相机画面时

外围相机朝坑内拍摄，稳定外部控制点未必能进入画面。现场必须画出控制点的实际视线，不能只在俯视图中写上R1/R2就认为可以校正。

若主视场无法获得足够控制，可增加专门的视觉控制观测站：控制相机观测稳定外部目标与测量相机刚性机架上的多靶标构件；通过事先标定的刚性变换，将机架姿态转换为测量相机的光学中心及姿态。控制相机自身也须受到稳定控制约束，所有机架应连接到同一外部坐标系。

该方案需要多视角几何、标靶构件刚度、坐标尺度、遮挡与同步验证。只在立杆上贴一个点不能测完整转动；只看机架也不能发现相机在安装板上滑动、镜头松动或内参改变。相机固定、刚性变换稳定性及光学检查均须另验收。这会增加设备数量，不能假定原16台已经包含全部控制观测设备。

控制网至少保留多个相互独立的参考来源和未参与拟合的检查点，观察参考之间的相对变化。若所有参考与相机共同移动，视觉网络可能无法识别整体基准漂移；必须用地质及结构依据选择稳定参考，并安排尺度与控制网复核。控制点数量增加不能消除这种不可观测性。

### 3.3 每个测量周期的流程

同步采集 → 检查曝光、清晰度、遮挡、时间戳 → 根据稳定控制估计当期相机外参 → 检查独立目标残差及位姿不确定度 → 三角交会墙面目标 → 输出相对初始坐标的法向、沿墙、竖向位移及质量状态。

内参不默认随距离变化，也不能认为终身不变；固定焦距、焦点、分辨率和裁切后，按温度与光学状态检查。外参随相机运动更新。短曝光下的一次清晰帧并不证明两台相机几何稳定；同步时差和曝光期间的运动要纳入误差。

对可识别的小幅运动，在经过试验的范围内更新外参；对控制失效、内参异常、严重晃动或超出验证范围的移动，停止相关测点的有效测量并发故障事件。小像素残差并不能独自证明毫米精度，应结合三维误差传播与独立检查。

不得自动重设墙面零点。重新安装或更换光学组件后，若能通过同一稳定控制网和同一墙面靶标接续坐标，则保留原累计基线；不能证明可接续时，明确标记数据断点及新版本。

## 4. 相机、镜头及防护箱

| 部件 | 初步要求 | 验证重点 |
|---|---|---|
| 相机 | 工业级、连续运行、固定成像模式；优先全局快门、硬件触发或可验证的精确同步 | 现场最差测点精度、曝光期间运动、真实温度范围、持续负载 |
| 镜头 | 固定焦距、机械锁焦及锁光圈；尽量固定光学配置 | 分辨率、目标最小像素、温度漂移、昼夜焦点一致性 |
| 完整防护组件 | 按现场选IP66或IP67等级的箱体及匹配密封接头；等级按装配后整体确认 | 雨尘侵入、内部冷凝、窗口透光与几何影响；IP67不代表可长期浸水 |
| 光学窗口 | 适合测量的平整光学玻璃、可维护、遮光遮雨 | 反射、眩光、平行度、温漂及安装应力；使用最终窗口参与标定与验收 |
| 遮阳与防雨 | 外部遮阳罩、合适雨檐和维护通道 | 单侧日照弯曲、风载、遮挡和雨水回流 |
| 除雾系统 | 温湿度记录，按露点控制窗口加热/除湿 | 加热滞回、窗口温差、局部热气流是否影响测量 |
| 补光 | 固定位置、稳定输出、防眩光、经验证的同一光谱模式 | 夜间目标曝光、焦点、阴影、湿墙反光及控制靶标照明 |

可初步试验将窗口温度保持在露点以上约3–5℃，再按实际结露、功率及测量误差调整。这是试验起点，不是通用保证；必要时配置干燥剂、合适透气件或除湿方案并记录维护周期。避免过热和将热气流吹入测量光路。

关闭自动变焦、自动对焦、电子防抖及未经标定的图像裁切/缩放。曝光和增益可在经过验证的范围内调整；白天与夜间使用明确配置，避免过长曝光和过曝。可见光/红外切换、IR-cut切换或更换窗口会改变光学状态，应分别标定或证明原参数仍有效。

窗口应便于清洁且清洁时不触碰精密机架。雨刷、风扇及吹扫装置可能引入振动或热流，动作期间暂停出有效测值，待检查恢复后继续。不要在没有光学验证时给测量窗口贴膜、涂防水剂或叠加普通透明板。

## 5. 天气与施工环境处理

| 工况 | 硬件与现场措施 | 测量处理 |
|---|---|---|
| 正常降雨 | 防雨箱、雨檐、滴水弯；检查窗口水滴与靶标反光 | 逐点判断；双视角均合格且误差受控才输出有效三维值 |
| 强降雨、雨帘或飞溅 | 及时排水，保护供电与箱体；雨刷/吹扫需验证 | 光路受扰时标记失效并发运行故障；不能把缺测认作墙面稳定 |
| 雾、凝露 | 窗口加热/除湿；记录露点和对比度 | 加热可消除窗口凝露，但不能消除空气中的浓雾；透视能力不足时失效 |
| 日晒与高温 | 遮阳、隔热、受控通风；热源远离测量光路 | 记录箱体和环境温度；检查热漂移、热空气折射和定位噪声 |
| 夜间及逆光 | 固定补光、遮光；条件允许时选择抗眩目标材料 | 验证夜间焦点与光学模型；过曝、阴影或目标识别异常时拒绝 |
| 大风 | 按当地风环境设计基础与框架，降低迎风面积 | 用图像/位姿检查与振动记录判定；晃动过大时停止有效输出 |
| 灰尘、泥浆及喷浆 | 防尘密封、清洁窗口；与施工方保护靶标和视线 | 模糊、覆盖、靶标身份不确定则拒绝；清洁后复核 |
| 低温、霜冻和雪 | 设备温区选型、加热、防积雪及线缆耐候 | 解冻后检查窗口、靶标及机架；冻融后检查基础和控制网 |
| 施工振动与撞击 | 独立安装、防撞、避开重车通道；事件记录 | 验证同步和短曝光；碰撞后检查结构、刚性变换及累计坐标可接续性 |

户外空气折射、雾和雨帘不是只靠防护箱即可消除。连续运行、连续获取图像与连续获得5 mm以内有效测值是不同指标，应分别验收。极端天气下全场光路同时失效，增加同位置相机也不保证恢复测量。

至少输出三类状态：有效测量、有效但接近质量限值、不可用。正式告警只使用满足约定误差条件的测值；质量临界状态说明原因，不能把放宽误差后的数值当作仍然达标。显示最后有效值时必须附原采集时间、数据龄期和当前失效状态，不参与新一轮正常判断。

长期缺测触发测量不可用事件，并按项目现场响应方案处理。若项目要求在浓雾等光学完全失效期间也连续获得有效位移，应另行设计经过同等级验收的独立观测链路；视觉硬件不能凭声明保证全气象有效率。

## 6. 墙面靶标与控制靶标

使用耐候编码靶标，具有稳定精密中心；尺寸由最远、最斜视测点的有效成像像素决定，不能统一指定一个尺寸。选择尺寸稳定、低反光、耐紫外和适合潮湿环境的材料，并验证热胀、翘曲及固定误差。

固定到真正被测构件，避免仅贴在浮灰、易剥落喷涂或松散表层。固定方法由支护设计允许的连接方式确定，不能随意在支护、防水或预应力构件上打孔。可用经过允许的预埋连接或其他机械固定；采用胶接时验证粘结与长期蠕变，而非默认长期可靠。

若使用背板，检查两点或多点固定、防转、风载、腐蚀和异种金属兼容。靶标中心与结构的相对移动会直接成为假位移。现场记录编号、照片、安装部位、固定方式、初始坐标和更换日期。

编码靶标只解决身份对应，不自动提供准确尺度或三维坐标。靶标损坏/替换后核查坐标接续，不直接把新靶标设成原零点。

## 7. 供电、通信与连续运行

现用设备历史记录补充：相关项目使用说明记录海康机器人MV-CS050-10GM通过P7接口输入9–24 VDC、典型功耗2.2 W@12 VDC、本型号不支持PoE。其IP40机身需增加户外防护。具体来源、针脚与连续供电方案见 [现用相机型号与供电核查](现用相机型号与供电核查.md)；连接前核对实际相机型号和供货线缆，不能把下文通用PoE建议直接用于该型号。

相机、边缘机、同步设备、交换机、补光和必要加热同时纳入UPS容量。分墙或分测量组划分保护和维护回路，故障不应拖停整坑；同组三维观测保持同步供电与采集，记录重启后同步恢复状态。接地、等电位、漏电及浪涌防护按现场电气设计实施。

若一组完整设备最不利功耗200 W，需要4小时备用，按效率0.9、可用放电深度0.8计算，最低标称储能约为200×4/(0.9×0.8)=1111 Wh；还需按老化、低温和设计余量增容。UPS的VA/W功率与Wh储能是两项不同要求，必须同时满足，不能只看VA数值。

短距离可用合适的工业以太网/PoE，端口功率核算加热和启动峰值；常规铜缆以太网单段按设备规范核查，通常不超过100 m。长距离、跨区及浪涌环境优先评估光纤和本地供电。交换机、UPS、机箱均需匹配真实温区与防护环境。

边缘端独立采集、质量检查、测量、缓存和本地事件判断；外网中断时继续工作，恢复后按采集时间补传。备份网络解决通信中断，不解决光路失效。结果和证据图像存本地并备份，记录原始时间戳、同步状态、标定和基线版本。

监控断流、重复旧帧、相机温度、UPS、磁盘、时间同步、控制残差和每个测点有效率。看门狗可重启采集服务，但重启成功后还要通过同步与质量检查才能恢复有效测量。

两个相机是三维测量所需的两路，并非天然容错备份。若关键测点要求坏一台后仍可测，需增加具有足够几何的第三路共同视角或重叠测量组，并控制供电、网络和控制网的共同故障。

## 8. 初步巡检与维护制度

| 周期或事件 | 动作与记录 |
|---|---|
| 每轮测量 | 图像、同步、控制/检查残差、外参变化、三维不确定度及逐点状态 |
| 每日自动检查 | 有效率、最长缺测、数据龄期、温湿度、UPS、磁盘、备份与未确认事件 |
| 每周现场检查，粉尘施工期加密 | 窗口、箱体密封、干燥剂、移位标记、线缆张力、锈蚀、靶标、补光和视线 |
| 每月及换季 | UPS负载试验、基础/机架/控制网复核、温漂与昼夜误差统计、备份恢复检查 |
| 大风、强雨、冻融、碰撞、重要施工变化后 | 按事件检查基础、控制目标、机架、光学和视线；通过检查后恢复有效测量 |
| 镜头、窗口、相机、机架或标靶变化后 | 标定与刚性关系复核、版本记录、同一外部坐标系接续检查 |

开箱、清洁、加热/雨刷动作、设备更换均记录维护时段。维护完成不能直接宣布恢复，应通过检查目标残差、同期双视角一致性及必要的精度检验。检查扭矩按维护规程执行，避免为了巡检而无依据地改变已锁定姿态。

## 9. 上线前的验证与验收

先做一个完整测量段，包含正式防护箱/窗口、基础、支架、靶标、控制网、补光、同步、UPS与软件。试验点覆盖该段最近/最远、角部和竖向不同深度；受控位移用专用装置施加，不向真实围护构件人为加载。

1. 已知三方向位移：验证法向、沿墙、竖向分别输出正确，覆盖小位移、正反向与预期量程，计入真值不确定度。
2. 相机运动注入：墙面试验靶标不动，在安全测试条件下对相机进行已知平移、转动；验证补偿后墙面不产生超过约定误差的假位移。再组合真实靶标运动，确认没有把真实位移一起消掉。
3. 安装与环境：验证装配后防雨、窗口结露、昼夜、日照温差、代表性振动、湿靶与清洁前后误差。全天连续试运行至少30天，另补未覆盖的季节和极端工况。
4. 故障注入：控制目标遮挡或移动、单机失效、两机失步、旧帧、断网、断电、磁盘满、重启和碰撞后模拟复位；检查故障状态、通知与恢复门槛。
5. 基线接续：维护前后使用同一外部控制及同一靶标证明累计量连续，不能证明时正确记录断点。

验收分别约定5 mm的统计/最大误差口径、各方向误差、环境适用范围、有效率、最长连续缺测和端到端延迟。将原图、拒绝帧、维护停机和无效周期全部纳入报告，不仅统计晴天有效帧。

静态检查点的变化门槛、风速/振动门槛、温度范围及允许外参变化均由试点确定，再写入正式配置；不能用统一的像素残差或任意“支架移动小于2 mm”代替三维总误差预算。

## 10. 每个观测站的交付台账

交付安装坐标与通视图、基础/支架设计及验收记录、相机与镜头序号、调姿锁紧记录、窗口规格、控制/检查目标及坐标、刚性变换标定、光学配置及温区、供电网络图、UPS容量与实测续航、标定/基线版本、环境验证报告、维护规程、备件及故障联系人。

最终确定高度、退距和机架规格还需坑深、支护图、周边稳定结构、当地温度/风/降水范围及可用安装坐标。已有三套布置图作为几何构想保留，不能把本细则理解为对其中某个布局已完成施工或精度验证。
