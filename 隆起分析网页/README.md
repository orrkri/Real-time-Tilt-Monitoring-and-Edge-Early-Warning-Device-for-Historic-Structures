# 墙体隆起分析网页

这个版本是“网页前端 + Python/OpenCV 后端”，真正计算在 `server.py` 中完成。

后端已按原来最严谨的 `相机标定校正_墙体表观位移分析_结果输出修正版.py` 逻辑接入：

- 使用相机内参 `CAMERA_MATRIX` 和畸变系数 `DIST_COEFFS` 做去畸变。
- 网页“相机参数”中默认填入现有参数；换相机、镜头、焦距或分辨率时，可以在这里填新的 `fx/fy/cx/cy/k1/k2/p1/p2/k3`。
- 用固定参考区估计整幅图像共同运动，优先 `cv2.findTransformECC(..., cv2.MOTION_AFFINE)` 仿射配准。
- 如果 ECC 失败，退化为固定参考区 `cv2.phaseCorrelate` 平移校正。
- 对待计算图做全局对齐后，在墙体分析区内分网格计算位移。
- 再拟合墙体自身整体仿射运动，输出局部残差，用来标记局部非均匀隆起更突出的区域。

首次运行：

1. 双击 `启动网页.bat`。
2. 等依赖安装完成后，浏览器打开 `http://127.0.0.1:5000/`。
3. 如果浏览器没有自动打开，可以手动复制这个地址访问。

使用流程：

1. 上传“基准图”和“待计算图”。
2. 在“框固定参考区”模式下，框画面中理论上不动的固定结构。可以框多个蓝色参考区。
3. 切换到“框墙体分析区”，框需要计算隆起的墙面区域。红色墙体区只保留最后一次框选。
4. 设置分区行列数和距离参数。
5. 如果不是原相机参数，展开“相机参数”填入新的标定值。
6. 点击“开始计算”。
7. 查看结果标注图，红色分区表示扣除墙体整体仿射运动后局部残差更突出的部分。
8. 可下载标注图和 CSV 结果。

说明：

- `corrected_wall_motion_px_median`：参考区全局校正后，墙体网格位移幅值中位数。
- `local_residual_px_median`：再扣除墙体自身整体仿射运动后的局部非均匀残差。
- 红色突出区域按 `local_residual_disp_px` 高分位和最大残差分区自动标记。
- 输出 CSV 会记录本次使用的相机参数，便于追溯。
- 两张图需要尺寸一致；BMP/PNG/JPG 等浏览器可读取的图片格式均可使用。
